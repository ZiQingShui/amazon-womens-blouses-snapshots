# Amazon 女式衬衫新品榜快照

公开看板按类目保存美国站新品榜 Top 100，支持切换类目、按日期查看及与指定历史快照对比。热销榜入口仅在类目配置了独立热销榜数据源后启用，避免把新品榜数据误当成热销榜。

顶部日期控件右侧的 `立即抓取` 会在本机处理器在线时立刻提交当前类目的手动采集请求。处理器平时只做轻量等待，不调用 Codex；只有点击按钮产生任务时才唤醒一次采集任务。重复点击不会并发执行同一类目、榜单和日期，已完成或失败的当天任务可以再次触发；按钮会显示本机未连接、等待、执行、完成或失败状态。每日自动抓取保持暂停。

`↑ 上传 Top 100` 提供另一条手动路径：选择与当前类目节点一致的新品榜导出 `.xls`，服务端核验名次 1–100、100 个唯一 ASIN、导出采集时间和文件格式，保存榜单行及 SHA-256，并把补齐详情的请求交给同一个本机处理器。现支持导出文件内实际为 UTF-8 网页表格的 `.xls`；真正的二进制 Excel 文件会明确报格式不支持。上传文件只能作为用户提供的榜单名次来源，不代表 Amazon 官方实时页面；产品图、品牌、促销、上架时间和 BSR 仍需 Ecomtool MCP 真正采集。处理器离线时请求排队，但不会完成或更新看板。失败时显示原因，缺少完整详情或图片不得发布。公开看板允许任何人上传，建议只上传可信导出文件。

## 本机手动处理器

本机处理器通过 `manual-capture-worker.local.json` 读取私密连接配置，并随当前 Windows 用户登录后启动，无需管理员权限。它每 2 秒检查一次普通任务接口；这只是本机与看板之间的轻量网络请求，不调用模型、不会产生 Codex 空跑额度。新任务到达后，处理器只向本对话发送一次采集指令。

- Chrome 与 Ecomtool 需要保持开启并已登录。
- 看板显示 `立即抓取` 时可以直接点击；显示 `本机未连接` 时不会提交无处理器任务。
- 处理器上线前超过 60 分钟的遗留请求会自动失败，避免误抓旧任务。
- 手动任务允许重新校验并替换当天快照，不允许覆盖其他日期。

## 数据结构

- `data/daily/YYYY/MM/YYYY-MM-DD.json`：不可变的每日快照
- `data/manifest.json`：日期索引与字段覆盖率
- `data/latest.json`：最近一期完整快照
- `data/status.json`：最近一次采集/发布状态
- `data/categories.json`：看板类目注册表
- `data/categories/<节点>/...`：新增类目的独立快照、索引与状态

`dist` 与 `docs` 始终写入相同数据；`docs` 供 GitHub Pages 发布。

## 手动添加类目

公开看板侧栏的 `＋ 新增类目` 可直接新增节点，无需管理员登录。类目选择器会合并本地目录与线上数据库，点击类目时按需加载尚未缓存的下级节点；未收录节点仍可手动输入。后来添加的类目可从侧栏删除，系统内置类目受保护；删除只会把类目移出共享看板，不会清理已经保存的历史快照，重新添加即可恢复。新类目会持久保存并显示为“等待首次采集”。每日任务会遍历所有已登记类目，不再只抓默认节点。

也可以在本机运行以下命令，依次输入 Amazon 类目节点和英文类目名称：

```powershell
python tools/add_category.py
```

新类目会立即写入 `dist` 与 `docs` 的统一类目清单，并显示为“等待首次采集”。之后按下面的方式为该节点发布第一份 Top 100 快照即可。发布器会读取本地清单；如果节点由网页新增，则会自动读取公开看板的最新类目清单，不需要再修改代码。

## 发布新快照

```powershell
python tools/publish_snapshot.py `
  --input path/to/enriched-products.json `
  --date 2026-09-12 `
  --captured-at 2026-09-12T08:30:00+08:00
```

发布新增类目时指定节点：

```powershell
python tools/publish_snapshot.py `
  --input path/to/button-down-shirts.json `
  --date 2026-09-12 `
  --node 2368383011
```

发布器只接受名次 1–100 完整、ASIN 唯一、标题和图片齐全、100 个商品均执行过详情采集，且详情来源明确为 Ecomtool MCP 的数据。商品链接与图片链接必须来自受信任 HTTPS 域名；Amazon 原图或本项目 GitHub Pages 托管的榜单导出图均可通过图片校验。已存在的同日快照禁止覆盖；未通过校验时不会覆盖 `latest.json`，只会在 `status.json` 记录失败原因。字段完整率不会把“未显示/无法获取”等占位文字当成有效数据；多个促销会去重后全部保留。
